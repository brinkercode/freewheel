## First release

freewheel turns a Blackmagic Speed Editor into a macro pad for everything else you do on your computer. No telemetry, no accounts, no analytics, always portable.

### What you can do

* Set any key to a shortcut, a media key (Play/Pause, Mute, volume, tracks), an app, a file or a website, or to hold or toggle a key.
* Keep several pages of keys and switch between them from the Speed Editor.
* Use the wheel to jog, shuttle or scroll, or turn it into a knob for system volume, an app's volume or screen brightness.
* See every key on a drawing of the Speed Editor; the key lights show the wheel mode, toggled keys and the page you're on.
* Connect by USB or Bluetooth, with the battery level shown.
* freewheel steps aside while DaVinci Resolve is open and takes the Speed Editor back when it closes.
* Back up your keys to a file you can also write by hand (see SCHEMA.md), and restore them on another computer.
* Lives in the tray or menu bar: switch it on or off, check for updates, start it when you log in.
* Help & backup → Device test shows what the Speed Editor sends, live.

### Download

Nothing to install: download the file for your system and run it.

* Windows 11: `freewheel-1.0.0-windows-x64.exe`
* macOS 15 (Apple Silicon and Intel): `freewheel-1.0.0-macos-universal.dmg`, drag freewheel to Applications
* Linux (x86_64): `freewheel-1.0.0-linux-x86_64.AppImage`

Your settings live in your user folder, so moving or replacing the app keeps them.

### Updates

freewheel checks for a new version when it starts, or when you click **Check for updates**. It downloads the file for your system, checks its signature, and swaps it in place when you restart, keeping your settings.
