# What must never appear in this public repository: file contents, file paths,
# commit messages, PR titles and bodies. Read by scripts/oss-readiness.mjs.
#
# One rule per line, `<category> <rule>`:
#   <category> re:<regex>     a case-insensitive JavaScript regular expression
#   <category> sha256:<hex>   a word whose lowercase sha256 is <hex>, for values
#                             that are themselves private (a word is a run of
#                             [A-Za-z0-9_-], or a whole e-mail address)
# `<category>@messages <rule>` applies only to commit messages and PR titles and
# bodies (release-please writes the release notes from commit subjects).
# Categories: infra, path, process, design, identity (identity matches are never
# printed). `identity` hits in commit
# metadata (author, committer, Signed-off-by) are warnings until the repository
# variable OSS_STRICT_IDENTITY is 1; everywhere else every hit fails.
# Add a word: printf %s 'word' | tr A-Z a-z | sha256sum
