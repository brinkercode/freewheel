## [0.2.0](https://github.com/brinkercode/freewheel/compare/v0.1.0...v0.2.0) (2026-11-20)

### ⚠ BREAKING CHANGES

* **config:** mappings files from 0.0.x no longer load; export them again from 0.1.0

### Features

* **device:** Speed Editor key and wheel LEDs driven from the engine ([#141](https://github.com/brinkercode/freewheel/issues/141))
* Start at login ([#99](https://github.com/brinkercode/freewheel/issues/99))
* **updates:** portable releases and a portable self-update ([#145](https://github.com/brinkercode/freewheel/issues/145))
* the wheel can step the volume, with a `Shift` held for finer steps

### Bug Fixes

* **device:** real Speed Editor auth response ([#140](https://github.com/brinkercode/freewheel/issues/140))
* header status never overlaps; tray and window share one On/Off ([#146](https://github.com/brinkercode/freewheel/issues/146))
