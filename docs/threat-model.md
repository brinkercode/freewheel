# freewheel threat model

Approved by brinkercode on 2026-11-03T17:41:32.778336+00:00: Owner approved in #personal-brinker: accept all

| id | kind | step or secret path | boundary | default | proven by | cards |
|---|---|---|---|---|---|---|
| T1 | untrusted_code | An imported freewheel-mappings.json can contain LaunchApp{path,args}, which runs any executable when a button is pressed | Import dialog → config validation → Launcher | Imported LaunchApp bindings stay disabled until the user explicitly opts in (owner answer r4q10, ADR-17) | C35 item 4: an import containing a LaunchApp without opt-in leaves no enabled LaunchApp binding (unit test) | Mapping import and export |
| T2 | untrusted_code | LaunchApp path and arguments from config are passed to the OS | Launcher adapter → OS process spawn | Spawn the process directly with an argv array (Command::new), never through a shell | C14 items 2-3: arguments containing ';', '&' and '$()' reach the mock Launcher unchanged, and the production code has no shell invocation (code ref) | App launch action |
| T3 | untrusted_code | The update installer downloaded from GitHub Releases is executed | tauri-plugin-updater → installer | Mandatory minisign signature against the pubkey in tauri.conf.json; https endpoint only; dangerousInsecureTransportProtocol absent | C36 item 1 config test; C38 item 4 manual check that an update with a tampered .sig is rejected | Tauri updater integration, Manual hardware test checklist per OS |
| T4 | untrusted_code | Pull-request code and its npm/cargo dependencies run in CI | GitHub-hosted ephemeral runner | Trigger on pull_request (never pull_request_target); permissions: contents: read; no secrets referenced | C2 item 5: a lint step fails if ci.yml contains 'secrets.', 'pull_request_target' or write permissions | CI matrix on hosted Windows and macOS runners |
| T5 | untrusted_code | Third-party actions and npm/cargo dependencies run in the release job where signing secrets are present | Release job on a hosted runner in the protected 'release' environment | Actions pinned by commit SHA; npm ci and cargo --locked; tag-only, with the owner as required reviewer; secrets only in the tauri-action step env | C37 item 3: a workflow lint checks every 'uses:' is a 40-hex SHA and the job declares environment: release | Release workflow: unsigned NSIS and signed universal dmg |
| T6 | secret | Apple Developer ID certificate, password and notarization credentials (APPLE_* secrets) | GitHub encrypted secrets → release-environment step env → temporary keychain on an ephemeral runner | Referenced by name only, never echoed, available only in the 'release' environment | C37 item 4: lint shows APPLE_* appear only in the tauri-action step env; grep finds no .p12 or secret value; gitleaks is green | Release workflow: unsigned NSIS and signed universal dmg |
| T7 | secret | Tauri updater private key and its password (TAURI_SIGNING_PRIVATE_KEY*) | Owner's offline storage → GitHub secret → release step env | Never committed; the owner keeps an offline backup; available only in the 'release' environment | C36 item 2 and C37 item 4: tauri.conf.json holds only the pubkey, and the gitleaks scan is green | Tauri updater integration, Release workflow: unsigned NSIS and signed universal dmg |
| T8 | untrusted_code | The settings webview calls Rust commands with data that can come from imported mappings | Webview IPC → Tauri command bridge | Capabilities allow only the used commands; strict CSP with bundled assets only; save_config validates before applying | C31 items 2-3: save_config rejects an invalid config, and a test asserts the capability file lists exactly the used commands | Tauri commands and status events for the settings window |
| T9 | untrusted_code | bmd.py downloaded to generate auth test vectors | Developer or agent sandbox | Copy only the pure bmd_kbd_auth function into a fresh empty dir, run it with python -I and no network, and commit only the vectors | C5 item 3: the vectors file records how it was generated, and the tests pass on the CI matrix | Port the Speed Editor auth algorithm |
